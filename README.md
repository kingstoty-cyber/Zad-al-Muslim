
# زاد المسلم v4.0

يتضمن هذا الإصدار مصحفًا كاملًا بالرسم العثماني (114 سورة، 6236 آية)، وفهرس السور، والبحث في الآيات، والعلامات المرجعية، وحفظ آخر موضع قراءة، وتغيير حجم خط المصحف، ومتابعة الختمة، ودعم العمل دون اتصال بعد فتح التطبيق أول مرة.

## مصدر النص القرآني

النص العثماني وبيانات السور من **Tanzil Project** بترخيص CC BY 3.0، وموزعان دون تغيير بواسطة مشروع `quran-json`. يحظر تعديل النص. توجد تفاصيل الترخيص في `QURAN_DATA_LICENSE.txt`.

## 🚀 كيفية التشغيل

### الطريقة السريعة
1. ارفع جميع الملفات إلى GitHub Pages أو أي استضافة ويب.
2. للاختبار على الكمبيوتر شغّل خادمًا محليًا داخل المجلد، مثل `python -m http.server 8000`.
3. افتح عنوان الخادم في متصفح حديث. لا تفتح `index.html` مباشرة، لأن قارئ القرآن يحتاج HTTP لقراءة ملف البيانات وتفعيل العمل دون اتصال.

### متطلبات التشغيل
- متصفح حديث يدعم JavaScript
- اتصال إنترنت لتحميل المكتبات فقط
- إذن الموقع لتحديد مواقيت الصلاة (اختياري)

## 🔧 التخصيص

### إضافة أذكار جديدة
قم بتعديل ملف `data.js` وأضف أذكارك في مصفوفة `AdhkarDB`

### إضافة سمات جديدة
أضف سماتك الجديدة في مصفوفة `Themes` في ملف `data.js`

### تعديل التصميم
قم بتعديل ملف `styles.css` لتغيير التصميم والألوان
