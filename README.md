
# زاد المسلم v4.8.2

## إصلاحات v4.8.2 — التصدير والمشاركة

- أصبح إنشاء الفيديو صامتًا على الهاتف مع بقاء صوت القارئ داخل الملف النهائي.
- رفع الحد إلى 10 آيات أو 3 دقائق للمقطع الواحد.
- اختيار جودة متوافقة VP8 أو عالية VP9 أو حجم أصغر.
- إرسال ملف الفيديو وحده عند المشاركة لرفع التوافق مع Android.
- إضافة «مشاركة صورة» بصيغة PNG كبديل فوري متوافق مع واتساب.
- إضافة نسخ نص الآيات واسم السورة والقارئ والمصدر.
- عرض رسالة داخل الواجهة بدل نافذة الموقع المزعجة عند رفض مشاركة WebM.
- توضيح أن التصدير الصامت في الويب يبقى زمنيًا، بينما MP4 السريع يحتاج تطبيق Android.

## إضافات v4.8.1 — مشاركة مقطع قرآني

- اختيار آية أو نطاق من آية إلى خمس آيات من مشغل الآيات المتزامن.
- إنشاء فيديو عمودي للحالات أو مربع للمنشورات داخل المتصفح دون رفع بيانات المستخدم.
- خلفية سوداء افتراضية، مع خلفيتين هادئتين خضراء وكحلية.
- تغيير النص تلقائيًا عند انتقال صوت القارئ إلى الآية التالية.
- إظهار اسم القارئ والسورة ومصدر التلاوة داخل المقطع وعدم نسبة التسجيل للتطبيق.
- تنزيل WebM أو مشاركته مباشرة عندما يدعم الهاتف مشاركة هذا النوع.
- حفظ إطار PNG كبديل للمتصفحات التي لا تدعم MediaRecorder أو مشاركة WebM.
- حد أقصى خمس آيات وتسعون ثانية لتقليل استهلاك الذاكرة والبطارية.
- عدم ربط الميزة بمصاحف قالون الكاملة أو بأي تسجيل غير مقسم آية بآية.

## إضافات v4.8 — جاهزية التطبيق والحفظ

- تنقّل داخلي متوافق مع زر الرجوع وسجل المتصفح وروابط اختصار PWA.
- مشغل صوتي مصغر دائم للآيات والسور مع السابق والتالي والتقدم.
- وضع حفظ يخفي نصوص الآيات مؤقتًا ويكشفها باللمس، وقوائم حفظ محلية مخصصة.
- مشاركة الآية كصورة PNG مصممة محليًا دون رفع النص أو الصورة إلى خادم.
- تنزيل الأجزاء والأحزاب كان متاحًا في مشغل الآيات، وتم الإبقاء عليه مع الاستكمال وإدارة التنزيلات.
- تشخيص محلي للاتصال وService Worker والتخزين والأخطاء، مع تصدير السجل.
- تحسين الوصول، مناطق الهاتف الآمنة، تقليل الحركة، واستخدام لوحة المفاتيح.
- Manifest وService Worker محسّنان، وهيكل Capacitor موثق لبدء التحويل إلى Android.
- لا توجد مزامنة قالون، ولا مزامنة سحابية صامتة. تدخل القوائم الجديدة في النسخة الاحتياطية المحلية.

- ملاحظة خاصة لكل آية مع التعديل والحذف والبحث والتصفية.
- صفحة موحدة لإدارة تنزيلات الآيات والسور الكاملة، مع التشغيل والحذف وعرض مساحة التطبيق.

## 🚀 كيفية التشغيل

### الطريقة السريعة
1. ارفع جميع الملفات إلى GitHub Pages أو أي استضافة ويب.
2. للاختبار على الكمبيوتر شغّل خادمًا محليًا داخل المجلد، مثل `python -m http.server 8000`.
3. افتح عنوان الخادم في متصفح حديث. لا تفتح `index.html` مباشرة، لأن قارئ القرآن يحتاج HTTP لقراءة ملف البيانات وتفعيل العمل دون اتصال.

### متطلبات التشغيل
- متصفح حديث يدعم JavaScript
- اتصال إنترنت لأول تحميل ولتحديث مواقيت الصلاة وتشغيل التلاوة غير المنزلة
- إذن الموقع أو إدخال الإحداثيات يدويًا لتحديد المواقيت والقبلة
