
# زاد المسلم v4.6.0

## إضافات v4.6 — مكتبة القرّاء والحفظ

- فهرس محلي ديناميكي يضم 67 تلاوة عربية مكتملة معلنة من المصدر، بدل تثبيت خمسة قراء داخل الكود.
- استبعاد الترجمات الصوتية وأربعة إصدارات أعلن المصدر أنها ناقصة الملفات.
- روايتا حفص وورش، مع بيان نمط التلاوة والجودة المتاحة لكل إصدار.
- مكتبة قابلة للبحث والتصفية، مع المفضلة وآخر القرّاء استخدامًا.
- تشغيل نطاق للحفظ باختيار آية البداية والنهاية.
- تكرار الآية وسرعات موسعة من 0.5× إلى 2×.
- مؤقت إيقاف بعد 10 أو 30 أو 60 دقيقة.
- تنزيل السورة الحالية أو جزء من الأجزاء الثلاثين أو حزب من الأحزاب الستين.
- استكمال التنزيل عند إعادة المحاولة؛ الملفات الموجودة في الكاش لا تُنزّل مرة ثانية.
- خيار Wi‑Fi فقط عندما يستطيع الجهاز تحديد نوع الاتصال.
- إدارة مركزية للتلاوات المحفوظة من الإعدادات.

## إضافات v4.5 — التلاوة الصوتية

- تشغيل مستقل لكل آية أو تشغيل متتابع لبقية السورة.
- خمسة قراء مع جودة مناسبة للهاتف، وحفظ القارئ والسرعة وعدد مرات التكرار.
- تكرار الآية مرة أو مرتين أو 3 أو 5 مرات أو بصورة مستمرة للمراجعة والحفظ.
- حفظ آخر آية وموضع زمني واستئناف التلاوة عند العودة.
- إبراز الآية الجاري تشغيلها ودعم أزرار الوسائط في Android عند توفر Media Session.
- تنزيل تلاوة السورة للقارئ المحدد إلى Cache Storage والاستماع إليها دون اتصال.
- إظهار تقدم التنزيل ومساحة التخزين المستخدمة، مع حذف تنزيل السورة دون المساس بالنص أو بيانات المستخدم.
- ملفات الصوت تُجلب عند الطلب من EveryAyah ولا تُضمّن في حزمة التطبيق، لتبقى النسخة خفيفة.

## إصلاحات التدقيق v4.4.1

- إصلاح فتح بطاقات تثبيت التطبيق والنسخ الاحتياطي والتنبيهات من تبويب الإعدادات.
- إصلاح ظهور إحصائيات المسبحة عند التنقل إليها.
- منع استخدام مواقيت مدينة قديمة بعد تغيير الموقع وفشل الاتصال.
- إزالة نسخة `user_location` عند حذف الموقع اليدوي فعلًا.
- ترميز اسم المدينة قبل عرضه لمنع إدخال HTML محلي.
- حماية فحص الإشعارات في المتصفحات التي لا تدعمها.
- معالجة فشل تحديث موارد PWA في الخلفية دون أخطاء غير ملتقطة.
- تحديث رقم كاش PWA لضمان وصول الإصلاحات للمستخدمين.

يتضمن هذا الإصدار مصحفًا كاملًا بالرسم العثماني (114 سورة، 6236 آية)، وفهرس السور، والبحث في الآيات، والعلامات المرجعية، وحفظ آخر موضع قراءة، وتغيير حجم خط المصحف، ومتابعة الختمة، ودعم العمل دون اتصال بعد فتح التطبيق أول مرة.

## 🚀 كيفية التشغيل

### الطريقة السريعة
1. ارفع جميع الملفات إلى GitHub Pages أو أي استضافة ويب.
2. للاختبار على الكمبيوتر شغّل خادمًا محليًا داخل المجلد، مثل `python -m http.server 8000`.
3. افتح عنوان الخادم في متصفح حديث. لا تفتح `index.html` مباشرة، لأن قارئ القرآن يحتاج HTTP لقراءة ملف البيانات وتفعيل العمل دون اتصال.

### متطلبات التشغيل
- متصفح حديث يدعم JavaScript
- اتصال إنترنت لأول تحميل ولتحديث مواقيت الصلاة وتشغيل التلاوة غير المنزلة
- إذن الموقع أو إدخال الإحداثيات يدويًا لتحديد المواقيت والقبلة
