# تسليم زاد المسلم UI13

هذا التسليم هو الإصدار `4.9.3-beta.5.3` من تطبيق زاد المسلم، ويتضمن قائمة جانبية صريحة لأقسام الأذكار بدل الفتح التلقائي أثناء التمرير.

## التثبيت

للاختبار على Android استخدم الملف `Zad-Al-Muslim-UI13-release-signed.apk`. لا تستخدم أي ملف باسم `unsigned`؛ ملف Release المرفق موقّع ومتحقق من v1 وv2 وv3. ملف `Zad-Al-Muslim-UI13-release.aab` مخصص للرفع إلى Google Play، وملف Debug مخصص للاختبارات الداخلية.

## التحقق من البصمات

بعد التنزيل شغّل:

```bash
sha256sum -c SHA256SUMS-UI13-FINAL.txt
```

## المستودع

تم رفع التحديث إلى الفرع `main` في مستودع GitHub، وآخر commit هو `64ddd15`.
