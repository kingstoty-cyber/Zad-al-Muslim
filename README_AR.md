# زاد المسلم — UI12

هذه النسخة تدمج واجهة أذكار قابلة للطي مع قاعدة أذكار محلية ومشغل صوت دائم.

## أهم ما تم دمجه

- 46 قسمًا و191 ذكرًا مستوردًا.
- 169 ملف MP3 محليًا تغطي 191 مرجعًا صوتيًا.
- طي شريط الأقسام عند النزول وإمكانية فتحه يدويًا.
- مشغل واحد يستمر أثناء التنقل.
- متابعة تلقائية اختيارية محفوظة محليًا.
- تسجيل الإنجاز عند حدث نهاية الصوت الفعلي فقط.
- منع تشغيل صوتين متزامنين بين الأذكار والقرآن والمسموع.
- دعم العمل دون اتصال عبر أصول محلية وكاش Service Worker.

## البناء

```bash
npm ci
npm run audit:release
npm run prepare:web
npm run android:sync
cd android
./gradlew clean assembleDebug
```

البناء المحلي وAPK Release الموقّع نجحا. اختبار جهاز Android حقيقي لم يُنفذ لعدم وجود جهاز أو محاكي متصل.
